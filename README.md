# 隐藏助手 4.0

用于 SillyTavern 的简洁楼层管理插件。仓库源自 [uhhhh15/hide](https://github.com/uhhhh15/hide)，4.0 已完全重写，只提供五项功能。

## 五项功能

| 功能 | 操作与效果 |
| --- | --- |
| 总开关 | 开启后应用当前聊天的规则；关闭后恢复本插件隐藏的楼层并暂停规则，规则仍保留。 |
| 隐藏指定楼层 | 输入单楼、范围或组合，点击“隐藏”。锁定楼层会自动跳过。 |
| 指定楼层始终不隐藏 | 在“始终不隐藏”中填写完整列表，点击“保存锁定”。已隐藏的指定楼层立即恢复，后续隐藏操作不能隐藏它们。 |
| 取消隐藏指定楼层 | 输入楼层后点击“取消隐藏”，同时移除对应隐藏规则；刷新、生成新消息、重新打开聊天后仍有效。 |
| 查询 | 面板显示实际已隐藏楼层和已锁定列表，支持“刷新查询”，连续楼层自动合并为范围。 |

打开输入框旁的扩展菜单 → **隐藏助手**，或在扩展设置中点击 **打开楼层管理**。

### 输入示例

楼层编号与酒馆一致，从 **0** 开始；范围包含两端。

| 输入 | 含义 |
| --- | --- |
| `3` | 第 3 楼 |
| `8-12` | 第 8 至 12 楼 |
| `0, 3, 8-12` | 第 0、3、8 至 12 楼 |
| `0，3、8～12` | 同上，支持中文标点 |

也支持空格、分号分隔，重复与相邻范围会自动合并。负数、小数、倒序范围及混杂非法文字会整次拒绝，不会部分执行。隐藏／取消隐藏不能提交空输入。

### 锁定优先

例如先锁定 `0, 3-4`，再隐藏 `0-8`，最终隐藏 `1-2, 5-8`，第 0、3、4 楼仍可参与上下文。

“始终不隐藏”是完整锁定列表：删除其中的楼层再保存即可解除部分锁定；清空后保存可解除全部锁定。解除锁定不会自动隐藏这些楼层，需要再执行“隐藏”。锁定会移除冲突的隐藏规则。

## 保存与生效方式

- 总开关是全局设置；隐藏和锁定规则保存在**各自聊天**中。同一角色的不同聊天、不同角色及群组聊天互不串用。复制或分支聊天时，随酒馆复制的聊天数据一起继承。
- 超出当前聊天长度的范围会保留，待楼层出现时生效。“已隐藏”只显示实际存在且隐藏的楼层；“已锁定”显示完整配置，计数只统计当前存在的楼层。可展开“查看隐藏规则”查看包括未来楼层的规则。
- 规则按当前楼层编号匹配。删除或插入消息后，按新编号重新应用，不跟踪原消息身份。
- 关闭总开关会恢复本版本标记为自行隐藏的消息；由酒馆、其他扩展或旧版本隐藏的消息保留原状，可用“取消隐藏”恢复。其他聊天会在打开时按开关状态恢复或应用规则。
- 总开关关闭时暂停隐藏、取消隐藏和锁定编辑，仍可查询。重新开启后恢复规则执行。
- 原生消息隐藏按钮也遵守锁定。插件会在消息变化、渲染及生成前重新检查规则，恢复被隐藏的锁定楼层。
- “隐藏”沿用酒馆的消息排除状态，不会删除消息；界面外观由酒馆主题决定。“不隐藏”表示不被本插件排除，最终是否进入请求仍取决于酒馆上下文长度等设置。

## 安装与更新

在酒馆“扩展”→“安装扩展”中填写：

```text
https://github.com/hsgpower/hide.git
```

已安装本仓库的用户，在酒馆扩展管理中更新，然后刷新页面。请只保留一份隐藏助手，避免旧插件同时运行。

也可下载 [ZIP 源码](https://github.com/hsgpower/hide/archive/refs/heads/main.zip)，解压覆盖插件目录。运行必需文件为 `index.js`、`floor-ranges.js`、`floor-state.js`、`style.css`、`manifest.json`；使用插件不需要安装 npm 依赖。

如果此前安装来自原作者仓库，需要重新安装本仓库，或者在插件目录执行：

```sh
git remote set-url origin https://github.com/hsgpower/hide.git
git pull --ff-only
```

### 从 3.x 升级

4.0 不再使用旧版的最近 N 楼、角色／全局规则、Token 统计、请求截断或更新弹窗。旧配置不会自动转成新规则；已隐藏消息保持现状并会出现在查询结果中。请在各聊天中重新设置所需的隐藏和锁定范围。

