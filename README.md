# 隐藏助手：指定楼层保留与取消隐藏

基于 [uhhhh15/hide](https://github.com/uhhhh15/hide) 的 `3.9.2`（提交 `0ca18fa`）修改，当前修改版版本号为 `3.9.3`，维护于 [hsgpower/hide](https://github.com/hsgpower/hide)。

## 安装

在 SillyTavern 的“扩展”→“安装扩展”中填写以下地址，安装后刷新页面：

```text
https://github.com/hsgpower/hide.git
```

已有原版插件时，也可下载本仓库的 [ZIP 源码](https://github.com/hsgpower/hide/archive/refs/heads/main.zip)，解压后将文件覆盖到原插件目录，再刷新酒馆页面。

插件目录以酒馆实际安装位置为准：常见位置是 `data/<用户目录>/extensions/hide/`；全局安装或旧版安装也可能位于 `public/scripts/extensions/third-party/hide/`。请覆盖原插件，不要同时保留两份隐藏助手。

运行文件包括 `index.js`、`floor-ranges.js`、`style.css`、`manifest.json`、`Logger.js`、`update.js`。其中 `floor-ranges.js` 是新增文件，覆盖安装时需要一并复制。使用插件不需要运行 npm。

本仓库是原项目的 fork，原仓库没有被修改。插件的版本检查指向本 fork；实际更新使用安装目录的 Git 远程地址。手动覆盖旧版文件不会更改这个地址，需要在原插件目录执行以下命令，才能使后续更新继续使用本 fork：

```sh
git remote set-url origin https://github.com/hsgpower/hide.git
```

如果仍从原仓库更新或重新安装，会恢复为原仓库版本。

## 指定楼层始终不隐藏

打开输入框左侧菜单中的“隐藏助手”，进入“隐藏楼层”：

1. 启用隐藏楼层功能并设置“保留最新的 N 条消息”。
2. 在“指定楼层始终不隐藏”中填写楼层或范围。
3. 按回车、移开输入框焦点或关闭面板，保存并立即应用。

输入示例：

| 输入 | 含义 |
| --- | --- |
| `0` | 保留第 0 楼 |
| `3-8` | 保留第 3 至 8 楼，含两端 |
| `0, 3, 8-12` | 保留第 0、3、8 至 12 楼 |
| 留空 | 移除保留例外，恢复只保留最新 N 条 |

也支持中文逗号、顿号、分号、空格分隔，以及 `~` 表示范围；重复和重叠范围会自动合并。负数、小数、倒序范围或其他非法文本会报错，不会部分应用。

例如当前有第 0 至 9 楼，N 为 `2`，始终不隐藏为 `0, 3-4`：最终保留第 **0、3、4、8、9** 楼，其余楼层隐藏。指定楼层不占用最新 N 条的名额，原先已隐藏的指定楼层会恢复。

保留列表与 N 一起按角色模式／全局模式保存。角色模式按角色卡或群组区分，同一角色的不同聊天共用配置。楼层编号从 **0** 开始，按当前编号匹配；删除消息后会按新编号重新应用，不跟踪原消息身份。超过当前聊天长度的编号会留在配置中，待对应楼层出现后生效。

## 取消指定楼层隐藏

在“取消指定楼层隐藏”中输入同样格式的楼层或范围，再点击“取消隐藏”或按回车。

此操作只恢复当前聊天中实际存在的指定楼层，并保存消息状态，不修改 N 或始终保留列表。已显示的楼层不重复处理，超出当前聊天的编号忽略。即使关闭自动隐藏，也能使用此操作。

这是一次性操作：关闭面板不会立即撤销结果，后续自动检查仍按已保存的隐藏规则处理。需要长期保留的楼层应填写到“指定楼层始终不隐藏”。

原有“立即将当前聊天所有楼层取消隐藏”按钮和 N 设为 `0` 的行为保留：恢复全部消息、清空 N，并保留例外列表，供下次启用时使用。

## 验证

开发环境使用 Node.js 24，运行：

```sh
npm ci
npm run check
```

自动化检查通过 jsdom 和 jQuery 加载实际插件模块及界面事件，模拟酒馆接口，覆盖范围解析、全量及增量隐藏、旧设置兼容、设置持久化、角色／群组／全局隔离、指定取消隐藏、关闭面板、关闭自动隐藏以及删除消息后的楼层变化。尚未在实际运行的 SillyTavern 实例中验证。

“不隐藏”表示允许该楼层参与上下文，最终请求仍受酒馆上下文长度等设置影响。请求拦截函数在配置保留例外时不再按 N 截断已经过滤过的消息列表，防止再次丢弃保留楼层；原插件 manifest 的拦截注册状态保持原样。
